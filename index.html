Abstract

Large-scale entomology imaging requires consistent mask-level insect identity tracking across frames, viewpoints, and cameras. Unlike standard video tracking, insect imaging often involves two challenging capture scenarios: multiple insects observed under changing camera viewpoints, and single specimens captured by synchronized cameras during 360-degree rotation, leading to potential identity ambiguity and incomplete masks. In this paper, we propose a unified motion-aware insect tracking framework with a shared segmentation representation and a regime-adaptive identity backend. The framework first segments insects using foundation segmentation models, then uses a Regime Router to select the identity strategy for each sequence. For multi-insect moving-camera sequences, it uses geometry-assisted identity memory to reduce cross-view identity switches. For low-ambiguity rotating-specimen sequences, where each frame typically contains a single insect and modern segmentation trackers are already highly reliable, the method uses mask-level tracking directly. Experiments on real insect imaging sequences show that adaptive routing improves identity consistency on multi-insect data while preserving high performance on rotating-specimen data compared with 2D-only and non-adaptive baselines.

Method

A shared representation. Two ways to preserve identity.

Foundation segmentation models produce candidate insect masks. A lightweight Regime Router reads background motion, residual object motion, and instance count to select the identity backend for each sequence.

01 / MOVING CAMERA

Geometry-assisted identity memory

Multiple similar insects remain static while viewpoints change. Lift masked pixels into 3D, build a point-cloud identity memory, and associate observations across views.

02 / ROTATING SPECIMEN

Direct mask-level tracking

A single specimen rotates in front of synchronized fixed cameras. Maintain one consistent specimen identity with SAM3 masks, without estimating 3D geometry.

Regime Router analysis

Moving-camera sequences have higher background motion and more instances. Rotating-specimen sequences have near-static backgrounds and a single dominant track.

The router uses fixed thresholds to invoke geometry when cross-view identity association benefits from it.
